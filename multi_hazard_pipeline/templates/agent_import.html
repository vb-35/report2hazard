1Zip of runs

A bundle from Compare → Download these runs imports as it is: it names each run's report and model and brings the report's segments and GIS context with it. Runs that are already here are skipped.{% if error %} Select the zip again after an error.{% endif %}

What an agent run folder must contain
  • placements.gpkg with a layer parts: one feature per mapped part with seg_id, part_id, label, geometry_role (event_extent, location or search_area), is_hypo, event_confidence, location_confidence, boundary_confidence, method, area_ha, report_area_ha
  • segment_results.csv: seg_id, status (located or unresolved), parts, reason
  • segments_evidence.csv: seg_id, part_id, quotes, reasoning, uncertainty, alternatives
  • optional: report.md, segments_map.html

A zip of several runs holds one such folder per run; the folder name becomes the model name.
